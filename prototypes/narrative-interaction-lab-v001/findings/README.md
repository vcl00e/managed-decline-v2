## Recording future tests

Create one Markdown findings record per substantial test or feedback session:

```text
NNN-YYYY-MM-DD-short-description.md
```

Store associated raw evidence beside it using a readable format where practical, for example:

```text
NNN-YYYY-MM-DD-short-description.json
```

Use the research structure in [`../docs/PLAYTEST.md`](../docs/PLAYTEST.md). Preserve raw evidence separately from interpretation so later design decisions can be traced back to what was actually observed.
