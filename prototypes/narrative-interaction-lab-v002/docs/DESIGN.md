# Design specification

## Research basis

`narrative-interaction-lab-v001` produced a strong directional result:

- dialogue baseline was preferred in every tested slice;
- decomposing coherent emotional intentions into required gesture chains damaged intimacy;
- optional environmental investigation remained promising but created affordance debt;
- visible goals and meters caused optimisation capture;
- dialogue should remain the primary interaction layer while the diorama, phone, time and occasional diegetic actions frame, vary and preserve the narrative.

That test used short scenes. It did **not** establish that dialogue-choice scenes can sustain a full session, that a compact map earns its place, or what support dosage works across a longer rhythm.

## Research question

> Can a dialogue-first, 25–40 minute evening remain engaging and inhabitable across map movement, focused conversations, an ensemble convergence, a public contradiction, an intimate scene, a phone interruption and visible aftermath—and do optional observation or sparse decisive action improve it without exposing the story as process?

## Controlled constants

Every treatment holds constant:

- the same single-evening narrative;
- the same six characters;
- the same three locations;
- the same opening freedom to visit any two locations in either order;
- the same third-location phone interruption;
- the same ensemble convergence;
- the same intimate break;
- the same public/institutional contradiction;
- the same four aftermath categories;
- the same absence of objectives, meters, scores and a player-facing state sidebar.

The prototype is comparative, but not content-identical line for line. Later dialogue may acknowledge information legitimately acquired by one treatment.

## Independent variable: narrative-support dosage

### A. Passive diorama

The player chooses destinations and authored dialogue. Positioning, movement, gestures, object handling and ambient changes are realised automatically.

Purpose:

- establish whether the dialogue-first evening is sustainable at all;
- test whether destination choice and passive staging make the map narratively useful;
- provide the minimum-support comparator.

### B. Optional observation

Adds exactly two optional discoveries:

1. **Hall inspection slip** — the main room passed; the kitchen circuit is isolated; the premises are not ordered closed.
2. **Pub continuity invoice** — the council’s substitute arrangement depends on a commercial minimum and restricts unsupervised under-eighteens.

Each observation:

- is local to a place where the object naturally exists;
- is clearly optional;
- disappears after use;
- changes later authored dialogue rather than a score;
- supports more than one interpretation or intention;
- does not imply a general search-everything interaction contract.

Purpose:

- test whether optional environmental discovery adds comprehension, curiosity and ownership;
- test whether players remember and voluntarily use evidence;
- expose affordance debt if the resulting dialogue does not fund the implications players form.

### C. Sparse decisive action

Adds explicit physical input only where the action changes the act’s social meaning:

- answer, decline or let each phone interruption ring while witnesses can observe the conduct;
- at the climax, physically hand the brass key to Maya, set it beside the disputed notice, close Tabitha’s hand around it, or leave it untouched.

Purpose:

- test whether sparse commitment gestures improve memory and ownership;
- determine whether the physical form adds meaning beyond an equivalent dialogue label;
- test whether even a small amount of explicit handling begins to feel like process.

The action is **not** decomposed into reach, pick up, walk, place and confirm. One input carries the complete meaningful act.

## Open-life construction

The opening deliberately does not say:

> Get Theo’s band a venue.

The player leaves work with a free evening and three visible attractors:

- music and a vulnerable community event at the hall;
- a social/commercial situation at the pub;
- Tabitha, a desirable relationship and a strange object at the bus stop.

The player may form several intentions:

- help Theo and Cal perform;
- protect Maya from being blamed;
- challenge or understand Sophie’s continuity arrangement;
- prevent a misleading public image;
- spend time with Tabitha;
- recover access to the hall;
- avoid becoming responsible;
- simply see what is happening.

A commitment is inferred only from conduct. The interface never converts it into a quest.

## Long-form rhythm

The intended rhythm is:

| Phase | Function | Interaction density |
|---|---|---|
| Leaving work | decompression and open intention | low |
| First destination | curiosity and local relationship | moderate |
| Map return | anticipation and self-directed sequencing | low |
| Second destination | contrast and developing interpretation | moderate |
| Phone interruption | world convergence; unchosen situation enters | one decision |
| Pub arrival | breathing space and orientation | low |
| Ensemble scene | simultaneous social meanings and public/private conflict | high |
| Practical update | immediate consequence and partial resolution | moderate |
| Intimate break | quiet character focus and possible withdrawal | low–moderate |
| Key climax | high-semantic commitment | one major decision |
| Aftermath | visible residue and future pull | no strategic handling |

The experiment should fail visibly if every phase feels like another menu, if low-density phases are dead time, or if the ensemble becomes incomprehensible.

## Scenario identity envelope

This slice is prototype content, not automatically a production scenario. It nevertheless uses a deliberate identity envelope so later tests can distinguish memorable authored identity from arbitrary branching.

### Premise invariants

- a community performance is displaced;
- official communication says continuity has been maintained;
- the substitute venue’s terms contradict that account;
- the hall’s physical fault is real but not the complete reason access ended;
- a scratched brass key connects personal history, institutional custody and possible future access.

### Dramatic invariants

- public reassurance versus lived inconvenience;
- legitimate safety concern versus defensive institutional framing;
- a group wanting different things from one event;
- private intimacy competing with public involvement;
- no single character holds the whole truth.

### Iconic anchors

- the green hall notice with a clean white amendment strip;
- the pub’s official continuity placard beside ordinary commercial clutter;
- the bus shelter in failing rain;
- Tabitha’s old coat;
- the scratched brass key;
- the final key-on-notice image, where chosen.

### Mechanical identity

- choose attention before a task exists;
- triangulate social and environmental accounts;
- decide whether and how to become involved;
- make one high-semantic commitment or withdraw;
- see a place, object and public account retain the result.

## Institutional contradiction

The contradiction is designed to avoid a puzzle with one correct villain.

Facts:

- a kitchen circuit fault exists and has been isolated;
- the main hall passed inspection;
- the hall’s caretaker/supervision contract ended;
- the council has not funded an immediate replacement;
- Sophie arranged the pub as an administratively defensible substitute;
- the pub agreement has commercial and safeguarding restrictions;
- the public notice compresses these facts into “continuity maintained.”

Interpretive possibilities remain open:

- Sophie prevented total cancellation under real constraints;
- the council is using a partial electrical problem to disguise a staffing decision;
- Maya is being left with responsibility without authority;
- the pub benefits commercially while genuinely offering space;
- reopening for one bounded song may be emotionally right and procedurally reckless;
- correcting the public account may improve truth while exposing individuals.

The prototype must fund these interpretations with plausible choices rather than forcing a single accusation.

## Optional-observation affordance debt

The v001 finding is treated as a hard constraint:

> Teaching inspection creates an expectation that resulting agency will be funded.

Therefore:

- there are only two discoveries;
- both discoveries unlock later dialogue at the ensemble scene;
- the invoice can be used to press commercial terms, youth-access terms or the broader public claim;
- the inspection slip can support reopening, a narrow correction, or defence of Maya;
- the player is never required to collect both;
- no ending is locked solely because an observation was missed;
- no exposed evidence inventory appears in the interface.

A playtest failure occurs if a participant formulates a reasonable response from an observation and cannot express anything close to it.

## Decisive-action threshold

A physical action earns explicit input only when at least one of these changes:

- possession;
- witnesses;
- consent;
- public/private meaning;
- information flow;
- commitment;
- persistent material residue.

The final key action passes this threshold. Routine staging—walking into the pub, sitting beside Tabitha, moving through rain, looking at a notice—does not.

## Map function

The map is not a conventional traversal challenge. It must perform measurable narrative jobs:

- expose simultaneous attractors without a quest announcement;
- let the player decide who receives attention first;
- create anticipation between scenes;
- give dense dialogue breathing room;
- make the third situation’s phone call feel like an interruption;
- establish social geography;
- make later convergence legible;
- support memory of where facts and relationships originated.

Travel is a short transition, not simulated walking time. If participants describe it as dead travel, the map has failed despite being visually attractive.

## Choice quality

Important turns should contain several plausible human positions rather than an obviously good route and bad alternatives.

Choice functions include:

- curiosity: which place first;
- expression: how to respond to a character;
- interpretation: what the contradiction means;
- commitment: whether to take responsibility;
- withdrawal: leave with Tabitha or decline involvement;
- public/private conduct: publish, contain, correct or ignore;
- relaxed texture: small responses that establish the protagonist without branching the whole evening.

The validator cannot prove dramatic quality. Facilitated retelling and interview evidence remain necessary.

## Visible feedback and residue

No choice should resolve only in hidden state.

Feedback layers used here:

- immediate character reaction;
- changed later line or available argument;
- changed possession of the key;
- changed public notice or photograph;
- changed access to the hall;
- changed shape of the music event;
- changed departure relationship with Tabitha;
- final lane tableau showing what physically remains.

The four ending categories are:

1. **Honest small set** — the pub hosts a deliberately limited performance under accurate framing.
2. **One song in the hall** — bounded, witnessed access creates a contested but lived reopening.
3. **Accurate public record** — the key and amended notice become an image that resists the official simplification.
4. **Leave with Tabitha** — the player rejects the role of local fixer; the world continues and settles without them.

These are not success/failure grades.

## Telemetry schema

Each run records:

```text
schemaVersion
prototype
run ID
variant ID
blind label and displayed order
start/end/abandon timestamps
step index and elapsed time
step kind: map | dialogue | observation | material
node/location context
action ID, label and semantic intent
before/after story snapshots
ending ID and residue
debrief ratings and notes
```

The story snapshot is included for causal reconstruction, not displayed to the player.

## Automated validation

Automated tests prove structural properties only:

- valid targets;
- reachability;
- no dead ends;
- treatment isolation;
- ordered opening permutations;
- phone-interruption correctness;
- observation consumption and later funding;
- ending coverage;
- absence of exposed system vocabulary and UI surfaces;
- readable JSON export implementation.

They cannot prove:

- whether the writing is compelling;
- whether 25–40 minutes is the actual duration;
- whether players form intentions spontaneously;
- whether the map is remembered;
- whether the key feels meaningful rather than contrived;
- whether support feels helpful or procedural.

Those require playtesting.

## Interpretation limits

The three versions should normally be tested between participants first. Playing the same 25–40 minute narrative three times in one sitting creates unacceptable familiarity and fatigue confounds. A smaller within-participant comparative sample can be run later with counterbalanced order and explicit acknowledgement of the repetition effect.

A single developer/tester session remains directional evidence, not population-level validation.
