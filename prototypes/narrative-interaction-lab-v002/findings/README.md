# Findings

This directory records evidence produced by `narrative-interaction-lab-v002` only.

Use readable files. Do not compress browser exports.

Suggested sequence:

```text
001-YYYY-MM-DD-initial-long-form-test.md
001-YYYY-MM-DD-initial-long-form-test.json
002-YYYY-MM-DD-follow-up-test.md
```

Each findings record should identify:

- prototype commit;
- participant context;
- displayed version order and actual treatment IDs;
- completed, abandoned and restarted runs;
- exported trace filename;
- immediate ratings and notes;
- participant retelling;
- remembered places, people, objects and movements;
- whether an intention formed before the interface named it;
- where dialogue fatigue began, if anywhere;
- whether optional observations were found and used;
- whether the decisive material action improved ownership or merely exposed process;
- decisions to continue, revise, simplify or stop.

Findings are evidence, not automatically accepted game design.
