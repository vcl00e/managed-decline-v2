# Findings

No human playtest findings have been recorded for v002 yet.

Add numbered reports here rather than rewriting the design specification after the fact.

Recommended naming:

```text
001-YYYY-MM-DD-first-blind-batch.md
002-YYYY-MM-DD-revision-retest.md
```

Each report should state:

- tester count and recruitment context;
- first-exposure versus replay status;
- assignment/counterbalancing;
- condition-level rating distributions;
- route, observation and decisive-action usage;
- session-duration distribution;
- remembered places, actions and residues;
- dialogue-fatigue and process-feeling evidence;
- choice-quality failures;
- confounds and implementation defects;
- decision: continue, revise, retest or kill;
- exact changes justified by evidence.

A single internal or automated run is verification, not a finding about player experience.
