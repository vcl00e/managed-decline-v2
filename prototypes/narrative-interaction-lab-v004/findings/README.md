# V004 findings

V004 is **concluded as a rejected prototype implementation**.

There was no formal playtest dataset. The prototype was rejected on inspection because its A/B/C treatments did not adequately instantiate the intended lived-space / activity-spine experience.

## Findings

- `001-2026-08-26-rejected-prototype-conclusion.md` — final conclusion, methodological failure analysis, evidence limits and carry-forward requirements.

## Interpretation

Do **not** use v004 as evidence that exploration, obligations or spatial narrative activity are weak. Those questions were not validly tested.

Its useful evidence is methodological:

> **A clean controlled experiment is not useful if its treatment abstracts away the experiential property being investigated.**

V004's principal failure was reducing the question of lived activity to:

```text
choose location
→ choose contextual action
→ spend authored beat
```

with a hidden work backlog layered onto one condition.

The corrective direction was to use a new scenario and build a genuinely continuous space with independently moving actors/events and concrete physical affordances. That direction led to v005.

No readable exported JSON trace exists for v004 because formal playtesting did not proceed.
